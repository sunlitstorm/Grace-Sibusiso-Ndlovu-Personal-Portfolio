Braille Text Analysis

Built a Braille translation system that converts English text into Braille representations using Unicode Braille characters and visual dot rendering. The system supports letters, numbers, punctuation, and selected contractions, with additional preprocessing logic to correctly handle numeric sequences using Braille number indicators. I originally built the project because I was interested in how language can be represented and translated through software. As I developed it, I learned more about Braille and accessibility technologies, which motivated me to expand the project into a web-based interface with a real-time Braille toggle using JavaScript. The Braille view can be switched on and off using a toggle in the navigation bar, allowing users to instantly convert on-screen text between English and Braille. To further explore accessibility, I added an audio feature that reads selected text aloud using the browser’s built-in speech synthesis. Users can highlight any text on the page and listen to it, providing an additional non-visual way of interacting with the content. The feature is accessed through a button at the bottom of the page.
