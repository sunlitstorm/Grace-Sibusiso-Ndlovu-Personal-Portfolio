NextBite - Data-Driven Food Waste Reduction System (Pomona College)

Designed and developed an independent sustainability initiative aimed at reducing post-consumer food waste at Pomona College through real-time data tracking and feedback systems. The project uses smart-bin scale sensors connected to data loggers, with Python scripts handling data collection, processing, and reporting. I worked on developing the software that connects the hardware inputs to a centralized system, enabling real-time aggregation of food waste data and preparation for public-facing visual displays. Beyond measuring waste, the system was designed to make its impact visible to students through public-facing displays that translate food waste into tangible outcomes, including estimates of how many meals could have been recovered and distributed to the local community through the Food Recovery Network at the Draper Center. The initiative was approved and funded by the President’s Office and is scheduled for launch in September 2026.

Braille Text Analysis

Built a Braille translation system that converts English text into Braille representations using Unicode Braille characters and visual dot rendering. The system supports letters, numbers, punctuation, and selected contractions, with additional preprocessing logic to correctly handle numeric sequences using Braille number indicators. The core translator processes input text into a nested Braille representation, which can be output in multiple forms including printed dot-matrix formatting and a Turtle graphics visualization that renders physical Braille cell structures. To improve usability and explore accessibility applications, I extended this system into a web-based interface for this website, that implements a real-time Braille toggle using JavaScript. While this project focuses on translation and visualization rather than tactile output, the underlying translation engine demonstrates a core component used in larger accessibility systems. Similar translation logic can be integrated into screen readers, refreshable Braille displays, and other assistive technologies that support people with visual impairments.
