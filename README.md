# Grace Ndlovu Portfolio

## Overview

This repository contains my personal portfolio website, built to showcase my academic background, technical skills, projects, leadership experience, and professional interests.

I am a Computer Science and Mathematics (Statistics) student at Pomona College with interests in software development, data analysis, artificial intelligence, and quantitative problem solving. This website serves as a central place to share my work and track my growth as a developer.

## Features

* Responsive portfolio website built with HTML, CSS, and JavaScript
* Light and dark mode toggle
* Custom Braille View inspired by my Braille Translation System project
* Project showcase section highlighting technical and independent projects
* Experience section featuring internships, leadership roles, and programs
* Direct links to GitHub, LinkedIn, and resume

## Projects Featured

### USAP Alumni Website

A full-stack web development project designed to strengthen connections between alumni and current students through account management, authentication, and profile features.

### NextBite

A data-driven food waste reduction initiative that combines sensor data, Python-based processing, and public-facing visualizations to encourage sustainability and reduce post-consumer food waste.

### Braille Text Analysis

A Braille translation and visualization system that converts English text into Braille representations using Unicode Braille characters and visual dot rendering. This project inspired the Braille View feature included in this portfolio.

## Why I Built This

I wanted a space that not only displays my projects but also reflects how I think about technology. Rather than presenting code alone, this portfolio highlights the intersection of software development, data analysis, accessibility, leadership, and community impact.

The Braille View feature was added as a way to connect one of my accessibility-focused projects to the portfolio itself, demonstrating how technical ideas can be incorporated into user experiences.
